**네, 캔버스(Canvas / WebGL)는 이 서비스의 개념을 설명하고 데모를 선보이기에 가장 강력하고 필수적인 도구입니다.**

과거 사진 한 장으로 내부 구조까지 복원하는 서비스는 글로 설명하면 다소 복잡하게 느껴질 수 있지만, **웹 캔버스 위에서 사용자가 직접 조립/분해 슬라이더를 움직여보고 부품을 클릭해보는 순간 개념이 즉시 직관적으로 이해**됩니다.

## 1. 캔버스(Canvas)가 데모에 가장 효과적인 3가지 이유

1. **분해도(Exploded View) 실시간 시각화**
* 단순한 3D 겉껍데기가 아니라 "실제 분할되어 조립 가능한 정밀 부품들의 집합"임을 직관적으로 보여줍니다.


2. **공차(Tolerance) 및 내부 기실 표현**
* 슬라이더를 조절할 때 부품 간 유격($0.2\text{mm}$)과 M3 볼트 체결 구멍, 내경 축 등이 맞물리는 모습을 투명도(Opacity)나 단면(Section Cut)으로 보여줄 수 있습니다.


3. **부품 사양(BOM) 상호작용**
* 캔버스 위 부품을 클릭하면 해당 부품의 3D 프린팅 권장 설정(레이어 높이, 채움 비율)과 필요 기성품(M3 볼트, 황동 인서트 등) 정보가 팝업되도록 구성할 수 있습니다.

## 3. 실제로 어떻게 확인해보고 검증하면 좋을까? (3단계 검증 로드맵)

### Step 1. 프로토타입 캔버스 구축 (Web-based Verification)

가장 빠르게 검증하는 방법은 **Next.js + React Three Fiber (R3F)** 또는 **Three.js**를 사용하여 단일 페이지 캔버스 웹앱을 만드는 것입니다.

* **3D 포맷 변환:** CadQuery나 Blender에서 익스포트한 `.step` / `.stl` 파일을 웹 표준인 `.gltf` 또는 `.glb`로 변환하여 캔버스에 로드합니다.
* **오프셋 벡터 분해:** 각 부품 객체(Mesh)에 이동 방향 벡터를 지정하고, UI 슬라이더 값($t = 0.0 \sim 1.0$)에 따라 부품 위치를 계산합니다.

$$\vec{P}_{render} = \vec{P}_{base} + t \cdot \vec{D}_{explode}$$



### Step 2. VLM 분석 결과와의 캔버스 연동 검증

AI 비전 분석 결과(JSON)가 캔버스 UI에 맞게 표현되는지 테스트합니다.

* **레이캐스팅(Raycasting) 검증:** 사용자가 캔버스 내부 부품을 클릭했을 때, VLM이 생성한 JSON의 부품 사양(`"type": "bolt_pattern"`, `"standard": "M3"`)이 가상 툴팁으로 정확히 매핑되는지 확인합니다.

### Step 3. 랜딩 페이지 / Pitch Deck 적용

* **사용자 반응 검증:** "과거 사진 업로드" 입력창 옆에 위의 **인터랙티브 캔버스 샘플**을 비치해 두고, 랜딩 페이지 방문자가 직접 분해도를 조작해 보게 만듭니다.
* **투자자/클라이언트 피칭:** 단순 발표 장표 대신 브라우저 캔버스를 직접 띄워 실시간으로 부품을 분해하고 치수를 변경해 보이는 시연을 진행합니다.
